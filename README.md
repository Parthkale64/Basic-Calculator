# Basic Calculator

## About

- This is a very basic calculator built with HTML, CSS, and JS.
- This is the first repository on my GitHub.
- It supports addition, subtraction, multiplication, and division.
- There are plans to add more functionalities in future commits.

## How to Use

1. Open your terminal and type the following command:
   ```
   git clone https://github.com/Parthkale64/Basic-Calculator.git
   ```
2. Open the `index.html` file in your preferred browser.
